# Лабораторная работа №1. Консольный бот
## 1. Назначение проекта
Вспомните материал и напишите программу, в которой необходимо реализовать итоговой проект «Консольный бот».

Бот должен запрашивать имя пользователя и временно сохранять его в списке пользователей. После этого пользователь получает доступ к основному меню программы.

Проект должен объединять знания по темам:

• ввод, вывод и типы данных;

• условия и логика;

• циклы;

• списки;

• функции.

Перед тем, как вы приступите к реализации кода, необходимо составить алгоритм.
Для создания и воплощения разрешается воспользоваться нейросетями, которые могут вам помочь с идеями, также приветствуются свои собственные
## 2. Основной функционал
Программа должна иметь главное меню:
```python
================================
    Добро пожаловать в бота!
================================

--- МЕНЮ ---
1 - Представиться
2 - Показать пользователей
3 - Калькулятор
4 - Выход
Выберите действие:
```
При выборе пункта меню консоль должна очищаться, после чего пользователю отображается выбранный раздел.

### 2.1. Авторизация пользователя и список пользователей
В меню добавить пункт, выбрав который можно будет ввести свое имя с клавиатуры, либо же запросить при запуске программы.

Введенное имя добавляется в список, в котором будут временно хранится имена пользователей. Также отмечу, что этот список можно будет вывести на экран с перечислением зарегистрированных пользователей.

### 2.2. Математические вычисления
В программе должно проводится как минимум одно математическое вычисление.

Например, добавить функцию, в которой будут происходить вычисления стоимости покупок, сдачу и общую стоимость нескольких покупок. Придумать и реализовать на ваше усмотрение.

### 2.3. Завершение программы
При выборе уникальной цифры или буквы из меню, бот должен вывести сообщение:
```python
Программа завершает работу...
3...
2...
1...

До свидания! 
```
Для обратного отсчёта использовать цикл и задержку. После завершения отсчёта программа должна закончить работу.
## 3. Входные и выходные данные
|Входные данные|Тип данных|Назначение|Пример|
|--------------|----------|----------|------|
|Имя пользователя|str|Регистрация пользователя|"Иван"|
|Выбор пункта меню|str/int|Выбор действия|1|
|Первое число|int/float|Первое значение для вычисления|30|
|Второе число|int/float|Второе значение для вычисления|5|
|Математическая операция|str|Выбор операции|"+"|

|Выходные данные|Тип данных|Назначение|Пример|
|--------------|----------|----------|------|
|Приветствие|str|Приветствие пользователя|"Привет, Иван"|
|Результат вычисления|int/float|Вывод результата|35|
|Список пользователей|list|Отображение сохраненных пользователей|1. Иван...|
|Сообщение об ошибке|str|Информация о неправильном вводе|"Ошибка!"|
|Обратный отсчет|int|Подготовка к завершению|3...2...1|
|Сообщение о завершении|str|Завершение программы|"До свидания!"|

## 4. Требования к программе
Программа должна:

• Использовать input() для получения данных от пользователя.

• Использовать print() для вывода информации.

• Использовать переменные разных типов.

• Использовать условия if, elif, else.

• Использовать циклы for и/или while.

• Использовать список для хранения пользователей.

• Использовать функции для разделения программы на отдельные блоки.

• Проверять наличие пользователя через not in.

• Обрабатывать ошибки ввода с помощью try-except.

• Иметь понятное консольное меню.

• При переключении разделов очищать консоль или имитировать её очистку.

• Иметь обратный отсчёт перед завершением программы.
