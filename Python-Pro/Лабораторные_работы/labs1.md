# Лабораторная работа №1
## Назначение проекта
Вспомните материал и напишите программу, в которой необходимо реализовать итоговой проект «Консольный бот».

Бот должен запрашивать имя пользователя и временно сохранять его в списке пользователей. После этого пользователь получает доступ к основному меню программы.

Проект должен объединять знания по темам:

• ввод, вывод и типы данных;

• условия и логика;

• циклы;

• списки;

• функции.

Перед тем, как вы приступите к реализации кода, необходимо составить алгоритм.
Для создания и воплощения разрешается воспользоваться нейросетями, которые могут вам помочь с идеями, также приветствуются свои собственные

## Входные и выходные данные
|Входные данные|Тип данных|Назначение|Пример|
|--------------|----------|----------|------|
|Имя пользователя|str|Регистрация пользователя|"Иван"|
|Выбор пункта меню|str/int|Выбор действия|1|
|Первое число|int/float|Первое значение для вычисления|30|
|Второе число|int/float|Второе значение для вычисления|5|
|Математическая операция|str|Выбор операции|"+"|
