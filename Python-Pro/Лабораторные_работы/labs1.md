# Лабораторная работа №1
Вспомните материал и напишите программу, в которой необходимо реализовать итоговой проект «Консольный бот».

Для реализации данного бота рекомендуется следовать следующим требованиям:

Бот должен уметь:
1. поздороваться с пользователем
2. запросить его имя
3. запомнить имя и добавить его в список пользователей
4. показать список пользователей
5. выполнить как минимум одно математическое вычисление
6. работать в цикле, пока пользователь не выберет выход
7. использовать функции для отдельных действий

Перед тем, как вы приступите к реализации кода, необходимо составить алгоритм.
Для создания и воплощения разрешается воспользоваться нейросетями, которые могут вам помочь с идеями, а также своим воображением:)
